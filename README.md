# Fase-4---Sistema-Integral-de-Gestion-de-clientes
Sistema de gestion de clientes, servicios y reservas para la empresa Software FJ, utilizando Python y programacion orientada a objetos. La aplicacion administra reservas de salas, alquiler de equipos y asesorias especializadas, implementando abstraccion, herencia, polimorfismo, encapsulamiento, validaciones sin utilizar bases de datos.
